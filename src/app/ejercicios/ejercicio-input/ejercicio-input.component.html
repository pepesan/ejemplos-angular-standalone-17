Crea un componente hijo que reciba datos del padre mediante @Input().

  • El hijo (ejercicio-input-llamado) declara tres inputs opcionales: cadena (texto), numero (número) y objeto (una clase Dato con un campo texto).
  • Su plantilla muestra los tres valores; el objeto, con el pipe json.
  • El padre usa el hijo dos veces: una sin pasar nada y otra pasando cadena, numero (el valor 3) y objeto.

Compara qué se ve cuando el input no se informa y cuando sí.

Este ejemplo declara sus entradas con el decorador @Input(). Desde Angular 19 existe input(), estable según angular.dev, que es la forma recomendada en código nuevo.

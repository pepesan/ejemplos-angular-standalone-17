Construye una lista a la que se añaden elementos desde un campo de texto.

  • Un campo de texto enlazado con [(ngModel)]; debajo, muestra en tiempo real su contenido.
  • Al enviar el formulario (con Enter) se añade el texto a la lista y el campo se vacía.
  • La lista empieza con «uno» y «dos» y se pinta con @for usando track. Si estuviera vacía, muestra «There are no items.» con @empty.

contenido del campo: {{cadena}}
    @for (item of listado; track $index) {

  • There are no items.

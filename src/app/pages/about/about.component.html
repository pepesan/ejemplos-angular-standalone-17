V1 · Clásicos

Para entender de dónde venimos

Conserva patrones clásicos y ejemplos históricos que ayudan a comparar distintas formas de resolver una tarea. V1 es una etiqueta didáctica, no una versión oficial de Angular.

V2 · Angular moderno

Para elegir herramientas actuales

Prioriza componentes standalone, Signals, formularios tipados, routing funcional y prácticas de accesibilidad. Los ejemplos se ajustan a las APIs disponibles en la versión de Angular de este repositorio.

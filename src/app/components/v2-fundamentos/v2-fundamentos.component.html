Fundamentos de Angular

Esta unidad presenta la arquitectura de Angular y el flujo de trabajo del proyecto. ECMAScript y TypeScript se estudian en el proyecto complementario de TypeScript.

Arquitectura de la aplicación

  • Los componentes organizan la interfaz y sus plantillas.
  • Los servicios encapsulan datos y comportamiento compartido; Angular los proporciona mediante inyección de dependencias.
  • Las rutas conectan URLs con componentes y pueden cargarse de forma diferida.
  • Las directivas y pipes modifican cómo se presenta o transforma la información en una plantilla.

Angular CLI en este proyecto

El repositorio incluye Angular CLI como dependencia local. Instala las dependencias una vez y ejecuta la aplicación y su API didáctica en terminales separados:

npm install
npm start
npm run backend

Para crear otro proyecto standalone desde cero, Angular CLI ofrece npx ng new nombre-del-proyecto --standalone. En este repositorio, npm start usa la configuración de proxy para conectar con el backend local.

Comunicación mediante estado compartido

Estos dos componentes son hermanos: ninguno recibe datos del otro mediante @Input ni le envía eventos con @Output. Ambos inyectan el mismo servicio raíz, que conserva el estado en un Signal.

Flujo: Componente A → servicio singleton → Componente B. El componente A actualiza el Signal; Angular actualiza el resumen y el valor calculado sin que el padre tenga que reenviar datos.

Este patrón integrado de Angular cubre estado compartido sencillo. Para aplicaciones con estado global más complejo, NgRx ofrece SignalStore como solución especializada.

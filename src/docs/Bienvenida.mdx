# Catálogo de componentes del curso

Cada componente de la aplicación tiene una story en Storybook, agrupada por carpeta en el menú lateral (`Componentes/<carpeta>/<Clase>`).

## Unidades del temario

1. **Fundamentos de TypeScript y Angular**: arquitectura Angular y CLI.
2. **Componentes, plantillas y Data Binding**: lista de tareas, props, directivas, control flow, seguridad en plantillas, condicionales, ciclo de vida, pipes, eventos e i18n.
3. **Comunicación entre componentes y Signals**: `@Input`/`@Output`, `input()`/`output()`, `signal`/`computed`, `model`, queries y `effect`.
4. **Servicios y comunicación HTTP**: servicios, `HttpClient`, interceptores y JWT.
5. **Formularios reactivos**: formularios de plantilla, reactivos tipados, Signal Forms y accesibilidad.
6. **Routing, Guards y Lazy Loading**: navegación, rutas anidadas, lazy loading y guards funcionales.

## Comandos

| Qué | Comando |
| --- | --- |
| Storybook en desarrollo | `npm run storybook` (puerto 6006) |
| Storybook estático | `npm run build-storybook` |
| Tests unitarios Angular | `npm run test:unit` |
| Tests de stories | `npm run test:stories` |
| Tests E2E (Playwright) | `npm run test:e2e` |
| Tests BDD (Cucumber) | `npm run test:bdd` |
| Todo lo anterior | `npm run test:all` |
